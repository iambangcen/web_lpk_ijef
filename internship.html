Program Unggulan LPK IJEF

Internship (Pemagangan / Ginou Jisshu)

Program pemagangan (Ginou Jisshu) merupakan program untuk mentransfer pengetahuan, teknologi, dan keterampilan ke negara berkembang, termasuk Indonesia. Status program ini akan berstatus sebagai pemagang dengan jangka waktu 3 sampai 5 tahun.

Persyaratan Utama:

  • Minimal 18 Tahun
  • Minimal lulusan SMA / SMK / Sederajat
  • Memiliki sertifikat kemampuan bahasa Jepang
